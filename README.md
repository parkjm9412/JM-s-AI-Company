## ⚡ 핵심 개념 3가지

### 1. AI는 비서, 결정은 내가 한다
- AI는 TOP 3까지 추천
- 당신은 TOP 1 선택 (1번만 결정)
- AI는 선택을 기다림 (혼자 진행 안 함)

### 2. 부서 시스템
- 한 부서 = 한 역할 (조사 → 기획 → 검수 → 제작)
- 각 부서는 명확한 "반려 기준" 가짐
- 기준이 없으면 AI는 "착한 말"만 함

### 3. 문서 중심
- AI는 AI_COMPANY.md를 매번 읽음
- 규칙은 문서에 적혀있음
- 반복되는 설명이 필요 없음

## 💡 FAQ

**Q: 무료로 쓸 수 있나요?**  
A: 네. 무료 Claude도 됩니다. Claude Code 유료 버전을 쓰면 더 강력합니다.

**Q: 처음엔 12개 다 해야 하나요?**  
A: 아니요. 시작은 5개만 해도 됩니다: 시장조사 → 기획 → 검수 → 기획2 → 비서실

**Q: 매일 해야 하나요?**  
A: 당신이 쓰고 싶은 만큼만 하면 됩니다. 하루 한 번이든, 일주일에 3번이든.

**Q: AI가 내 말투를 못 따라 해요.**  
A: AI_COMPANY.md의 "금칙어"에 "이건 쓰지 마"를 적으세요. "이렇게 써줘"보다 훨씬 잘 됩니다.

**Q: 일부만 변경하고 싶어요.**  
A: 자유롭게 수정해서 쓰세요. 템플릿이니까요.
